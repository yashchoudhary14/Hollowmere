# Reference images

Two kinds of reference, both in `docs/design/ref/`:

1. **Technical (exact) - generated from the same data the builder uses.** Use these to check your build: floor plans with every prop numbered (`Hxx_plan.png`), front-left and back-right massing views (`Hxx_massing_front.png`, `Hxx_massing_back.png`) and the village map (`village_map_v2.png`). After building, render the same views with `tools/unity.ps1 shot` and compare side by side.
2. **Mood (look & feel) - AI-generated or photos.** For each house, `Hxx_mood.png` (optional). Prompts are on each house page and in `docs/design/mood_prompts.txt`. Generate them in Higgsfield, Gemini or ChatGPT (see `docs/AI_HELPERS.md`) and save them with that name; Claude Code reads PNGs with its Read tool.

Mood images are for colour, material, wear and atmosphere ONLY - when they disagree with the plan/massing, the plan wins.
