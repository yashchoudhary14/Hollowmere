# Art and lore requests (for Gemini / ChatGPT)

Generated by `tools/housegen/gen_requests.py` from the house JSON. How to use these with Gemini and ChatGPT: `docs/AI_HELPERS.md`.
Save every file **exactly** at the path given (make missing folders). Claude Code picks them up from the `incoming` folders, resizes, imports and wires them. Nothing here is needed for the game to run: missing files fall back to plain materials.

Ground rules for every image: fictional people only (never a real person or a celebrity), no brand logos, no copyrighted characters, late-1970s rural English village, damp and faded, nothing gory. Keep the prompts' aspect ratios.

## A. Mood images (reference only, not in the game)

One per house plus two street views. The prompts are in `docs/design/mood_prompts.txt` (file name on one line, prompt on the next). Generate at 16:9, pick the best of 2-4, save as `docs/design/ref/<file name>`. Claude Code compares its screenshots with them for look and mood only; the plan and massing PNGs stay the source for geometry.
