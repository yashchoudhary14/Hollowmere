# Playtest log

Newest first. Claude Code adds entries with `/playtest`. Unresolved items take priority over new features.

Each entry has the date, the milestone, what was tested, and a list of findings marked **bug**, **feel** or **idea**, each with a status of `open`, `fixed` (with the commit) or `won't fix` (with the reason).
